# M02 Hunger and Saturation Display

## FOOD-01: Less intrusive hunger

Hunger should be more forgiving, not a second survival-management game. The player should spend less time routinely eating while traveling, mining, building, and exploring. **Don't add** thirst, nutrition requirements, food spoilage, stamina, temperature or other maintenance meters.

### Exhaustion changes

Use an initial **0.5x multiplier** to exhaustion generated by routine physical activities:

- Sprinting.
- Jumping (including sprint-jumping).
- Swimming.
- Block breaking/mining, to the extent the target vanilla version actually applies exhaustion for that action; do not fabricate nonexisting penalties.

Keep **vanilla** for:

- Combat attack exhaustion.
- Natural healing/regeneration expenditure.
- Hunger potion/effect behavior.
- Ordinary walking if it generates no exhaustion in vanilla.
- Any unrelated food/stat effect not listed above.

Implement changes as multipliers or clean targeted hooks, not one blanket modification that halves combat/healing or breaks food consumption. A balance config key should permit later playtesting adjustment.

### Saturation HUD

- Include an **enabled-by-default** saturation visualization in normal survival HUD, similar in clarity to AppleSkin's overlay. Show saturation as a distinct overlay on the existing hunger icons or another tasteful visual closely tied to them.
- Display actual server-synchronized player saturation, not a guessed value derived from hunger level. Explain any client synchronization limitations or version-specific mechanisms.
- No AppleSkin mod dependency is required. Do not add duplicate overlays if the actual development environment already includes a comparable hunger display; report observed conflicts rather than rewriting the HUD extensively.
- Keep placement/resolution appropriate with differing GUI scales and reduced 27-slot inventory UI.

## Tests

- Using matched clean worlds and fixed activity lengths, measure baseline vanilla exhaustion/hunger/saturation against modded behavior for sprinting, jumping, swimming, and relevant block breaking.
- Verify exhaustion is ~half for targeted activities, while same-duration combat and health regeneration remain unchanged.
- Confirm saturation overlay moves correctly after eating, exertion, regeneration, and world reload; capture UI screenshot at a nonzero saturation value.
- Creative/spectator and hiding the HUD should behave predictably without extra clutter.
