# Milestone 02 ore and rock sampling (GEO-01, ORE-01, ORE-02)

Generated by `OreSampler` (`src/gametest/.../sampler/OreSampler.java`) on **real normal-terrain worlds** (dedicated server, `level-type=minecraft:normal`), not the superflat game-test world. Every seed is generated twice:

- **control**: a `git worktree` of commit `a3f53d3` (Milestone 01 only, so vanilla world generation) with the same sampler file added;
- **Simple Block**: this repository with the default tuning (`config/simple_block/tuning-defaults.json`).

**Method.** For each seed the sampler finds sample regions by surface biome (4 ordinary, 2 deep ocean, 3 mountain, 3 desert/badlands/river) from nine fixed search origins up to ±2,500 blocks, generates each 5×5-chunk region completely and counts every block from bedrock to the surface. Biome layout does not change, so both runs sample identical coordinates. Each column is assigned the category of its surface biome. **Eligible rock** is stone-depth rock (stone, granite, diorite, andesite, stone ores) or deepslate-depth rock (deepslate, tuff, deepslate ores); raw-ore blocks of large veins count as rock of their depth. Densities are ore blocks per 100,000 blocks of eligible rock. Separately it finds the nearest trial chambers, and the strongest iron and copper ore vein within ±768 blocks of spawn.

Data: `counts.csv` (per seed/label/region/category/host), `profile.csv` (per y), `deposits.csv`, `veins.csv`, `trial-chambers.csv`, `regions.csv`. Commands: `tools/ore-sampling/run_sampler.sh <label> <repo> <seeds…>`, then `tools/ore-sampling/analyze.py` and `composite.py`. Seeds: 12345, 42, 8675309, 20261011, -1029384756, 777777, 3141592653, -55555.

**Caveat.** Removing and adding features shifts the random seeds of some later features in the same generation step, so individual ore blobs, lichen and similar decorations sit in different places in the two runs. Comparisons are statistical, not block-for-block.
