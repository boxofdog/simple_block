# Player-facing dev-text cleanup log

Capture intrusive debug/tutorial text seen during playtesting. **Not a current implementation assignment** except where explicitly absorbed into a future milestone. **M11 owner direction (2026-10-13) supersedes the older cart-inspection exception:** freight-cart **look-at and click-originated cargo/flavor text are both to be removed**; physical fill states and cargo transfer are the normal feedback, with exact internal counts still used for logic/tests. Keep non-cart useful feedback where appropriate.

**Owner direction 2026-10-14 (supersedes the above for the whole mod): no floating text at all.** Action-bar messages and labels over things felt like development remnants. M11 removed every one the mod sent (vanilla's own messages, GUI labels and inventory tooltips stay). Each removed message is listed below, verbatim, with whether the player now lacks feedback that something should replace (sound, particle, animation, model state). The outcome each message described is still computed and recorded server-side (`feature/Feedback`), never shown, so replacements can be built from it. "Replace?" key: **Yes** = a refusal or state the world does not show; **Maybe** = partly visible; **No** = the world already shows it.
